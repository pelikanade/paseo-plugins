# Headless sync through the official CLI

`paseo-obsidian` spawns the official `obsidian-headless` (`ob`) CLI to log in, register a vault, and run `ob sync --continuous`, rather than reimplementing the Obsidian Sync protocol or depending on a community client. The protocol is end-to-end encrypted and undocumented, and the community implementations are reverse-engineered experiments that break on protocol changes; the official client is maintained by the vendor and already supports the three behaviours this plugin needs (`pull-only` mode, `--continuous` watching, `--json` status). The cost is deliberate and visible: the package is `UNLICENSED` and requires Node ≥ 22, so the plugin cannot bundle or fetch it, installation is a documented host prerequisite, and a missing binary surfaces as an explicit `ob_missing` state instead of a silent failure. Considered and rejected: a git-based vault (`obsidian-git` plus a repository) which needs desktop-side setup and loses Sync semantics, and the desktop Local REST API, which requires the desktop app to be running.
